Sincronização entre aparelhos

Para que todos vejam os pedidos ao mesmo tempo (você, sua irmã, engenheiros e o marmorista), o app usa o banco gratuito Google Firebase. É de graça (plano Spark) e a configuração é feita uma única vez:

  1. Acesse console.firebase.google.com com sua conta Google e clique em Criar projeto (ex.: civilnobre-granito). Pode desligar o Analytics.
  2. No menu Criação → Firestore Database → Criar banco de dados → local southamerica-east1 → iniciar no modo de teste.
  3. Em Regras, publique: allow read, write: if true; (dentro do match já existente).
  4. Na tela inicial do projeto, clique no ícone </> (app da Web), registre com qualquer nome e copie o objeto firebaseConfig.
