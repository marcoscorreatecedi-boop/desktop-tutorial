🚀 Passo a Passo — Importar no Make.com

1

Acesse o Make.com e crie um novo Scenario

Clique em Create a new scenario → botão … (três pontos) → Import Blueprint → selecione o arquivo make-agente-whatsapp-civilnobre.json.

2

Criar o webhook (Módulo 1)

Make.com pedirá para selecionar ou criar um hook. Clique em Create a webhook, dê o nome "Webhook Z-API Civilnobre" e copie a URL gerada (algo como https://hook.eu1.make.com/abc123...).

3

Preencher a Anthropic API Key (Módulo 2)

No módulo HTTP (Claude API), localize o header x-api-key e substitua o placeholder pela sua chave real. Obtenha em console.anthropic.com → API Keys.

4

Preencher o número do Marcos (Módulo 5)

No módulo HTTP da rota IMPORTANTE (alerta), edite o campo data e substitua 5531XXXXXXXXX pelo número real, sem espaços ou traços, começando com 55.

5

Registrar o webhook no Z-API

No painel Z-API, vá em Webhooks → cole a URL do passo 2 em Webhook de Mensagens Recebidas (on-receive). Salve. O botão "Configurar agora" fica visível quando nenhum webhook está cadastrado.

6

Ativar o Scenario e testar

Ligue o toggle do Scenario no Make.com (ON). Envie uma mensagem de teste para o número Z-API pelo WhatsApp de outro celular. Verifique o histórico de execuções no Make.com.

🤖 System Prompt do Agente (preview)

Você é o agente de triagem de mensagens WhatsApp da Civilnobre Engenharia e Império Nobre Imóveis, em Contagem/MG. Analise a mensagem recebida. Responda APENAS com um JSON válido puro — sem markdown, sem blocos de código, sem texto antes ou depois do JSON. Campos obrigatórios: - classificacao: SIMPLES ou IMPORTANTE - resposta_automatica: mensagem profissional ao cliente (cite o empreendimento quando relevante) - resumo_para_marcos: string vazia se SIMPLES, resumo curto se IMPORTANTE - e_lead_novo: true ou false Critérios: SIMPLES = saudações, agradecimentos, confirmações, perguntas genéricas, fornecedores rotineiros. IMPORTANTE = lead novo, interesse em compra, solicitação de visita, negociação, reclamação, proposta urgente. Empreendimentos: - Mykonos: Av. Cruzeiro do Sul, Jardim Riacho das Pedras, 8 unidades, alto padrão - Concórdia: 5 unidades disponíveis - Pantheon: 6 unidades, Contagem

Modelo usado: claude-haiku-4-5-20251001 — rápido e econômico para triagem. Pode ser alterado para claude-sonnet-4-6 para respostas mais elaboradas.
